## 問題
朋友經營的黑膠店，每次有新的黑膠要上架，就要從新庫存手動複製，包含專輯名稱、樂手、年份、價格等等的資訊，然後貼到words影印出來。

一次上架至少都50張黑膠左右，一個黑膠要複製8個欄位，這樣上架一次光是產生貼紙就要複製400個欄位，每週至少一個小時在手動複製這些東西。

## 解法
我做了一個Sticker Maker，讓朋友可以直接設定
1. 這次要上架的庫存
2. 需要生成貼紙的模板
3. 輸出位置

讓程式自動填完的貼紙，一秒就全部產完。

用到的東西都很基本：
1. Vibe coding: Codex 5.3 Medium + vs code
2. tkinter: UI介面
3. 用pyinstaller把python轉成macos app
4. 用create-dmg讓朋友不用裝python就能跑程式
