這張圖介紹資料庫優化的另一個面向：分區。

在非常大的表裡，如果常見的情境是依照年份去做查詢，就沒有必要在一個經年累月的表上搜尋。

如果可以依照年份切出不同的表，每個小表都可以有自己的索引，可以大幅增加搜尋的笑率。

這張圖最右邊的 1, 2, 3, 4顯示出每個步驟的順序：

1. 我們要先定義如何切分表格
2. 建立 File Groups
3. 每個 File Groups 之下可以指定要存放哪些 Data files
4. Partition Scheme 利用 partition function 對應到剛才建立好的 File Groups
5. 實際建立一個表格並指定 Partition scheme
	```sql
	CREATE TABLE Orders (...)
	ON PS_Order(OrderDate)
	```
6. 實際插入資料時，就會依照日期存放到對應的 File Groups
